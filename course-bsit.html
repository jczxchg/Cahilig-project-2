Bachelor of Science in Information Technology

The Bachelor of Science in Information Technology (BSIT) program equips students with the technical expertise and practical skills needed to design, develop, implement, and manage modern computing systems. Combining foundational theory with intensive computer laboratory training, this degree prepares future IT professionals to solve real-world business and organizational challenges through technology.

Students gain hands-on experience in software engineering, web and mobile application development, database administration, network infrastructure, and cybersecurity, culminating in a capstone project and supervised industry internship (OJT). Graduates are well-prepared for high-demand careers as software developers, systems analysts, network engineers, database administrators, and IT project managers.

What You'll Learn

  • Programming fundamentals, data structures, and object-oriented design
  • Full-stack web and mobile application development
  • Database design, SQL, and enterprise data management
  • Computer networking, cloud computing, and system administration
  • Information assurance, cybersecurity, and network defense
  • Human-computer interaction (HCI) and UI/UX design principles
  • Systems analysis, software engineering, and agile project management
  • IT capstone research, technopreneurship, and industry practicum (OJT)

Software Engineering & Mobile App Development

Designing, coding, and testing scalable software solutions for desktop, enterprise, and mobile platforms.

Students master object-oriented programming, algorithms, and modern development frameworks to build reliable applications from the ground up. This track prepares graduates for high-demand roles as full-stack software developers, mobile app engineers, and quality assurance specialists.

Web Technologies & UI/UX Design

Crafting responsive, accessible, and user-centered digital experiences for the modern web.

Learn front-end and back-end web architecture alongside human-computer interaction (HCI) and interface prototyping. Graduates are equipped to work as web developers, front-end engineers, and UI/UX designers for tech startups, digital agencies, and global enterprises.

Network Administration & Cybersecurity

Building resilient network infrastructures and protecting critical systems against cyber threats.

Gain hands-on training in routing, switching, server configuration, ethical hacking, and information assurance protocols. This specialization prepares students for careers as network engineers, cybersecurity analysts, and systems administrators across banking, telecom, and IT sectors.

Database Administration & Cloud Computing

Architecting secure, high-availability data storage and cloud infrastructure for modern organizations.

Explore relational and NoSQL database systems, data warehousing, backup recovery, and cloud deployment models. Graduates are ready to serve as database administrators (DBAs), cloud support engineers, and backend infrastructure specialists.

IT Project Management & Business Analytics

Bridging technical execution with business strategy, agile leadership, and data-driven decision-making.

Develop skills in systems analysis, agile project workflows, IT governance, and enterprise data analytics. This path prepares graduates to become systems analysts, IT project coordinators, technical consultants, and tech startup founders.
